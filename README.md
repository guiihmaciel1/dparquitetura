# Debora Pieri Arquitetura

Site institucional para o escritório de arquitetura Debora Pieri, localizado em Mirassol e São José do Rio Preto, SP.

## 🏗️ Sobre o Projeto

Site moderno e elegante desenvolvido com Next.js 15, apresentando:

- **Design Contemporâneo Urbano** - Refletindo o estilo arquitetônico da Debora
- **Atendimento Humanizado** - Comunicação que transmite sensibilidade e dedicação
- **SEO Otimizado** - Para buscas locais na região de Mirassol e Rio Preto
- **Performance** - Otimizado para carregamento rápido
- **Responsivo** - Adaptado para todos os dispositivos

## 🛠️ Tecnologias

- **Next.js 15** - Framework React com App Router
- **TypeScript** - Tipagem estática
- **Tailwind CSS 4** - Estilização utilitária
- **Framer Motion** - Animações suaves
- **Lucide React** - Ícones

## 📁 Estrutura

```
src/
├── app/
│   ├── page.tsx              # Home
│   ├── layout.tsx            # Layout principal
│   ├── globals.css           # Estilos globais
│   ├── sobre/                # Página Sobre
│   ├── projetos/             # Galeria de projetos
│   ├── servicos/             # Serviços oferecidos
│   └── contato/              # Formulário de contato
└── components/
    ├── layout/               # Header e Footer
    ├── sections/             # Seções das páginas
    └── ui/                   # Componentes reutilizáveis
```

## 🚀 Como Rodar

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Rodar produção
npm start
```
